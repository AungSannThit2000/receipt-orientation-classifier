# Reproducibility

The public repository reproduces inference and evaluation logic but does not contain the receipt dataset. Training requires a locally supplied dataset and a compatible license.

## Environment

The verified environment is Python 3.10 on CPU. Create a clean virtual environment and install both runtime and experiment dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-training.txt
```

## Step 1: prepare source receipts

Point the preparation script at a folder of upright receipt photographs:

```powershell
python src/prepare_dataset.py `
  --source-dir C:\path\to\receipt-images `
  --overwrite
```

Review `data/manifests/review_required.csv` and the generated QA grids. Add visual corrections to `config/orientation_overrides.csv`, then rerun preparation. Do not train until every canonical top-side decision is approved.

Expected Draft 2 reference totals:

- 200 files found;
- 198 unique source receipts after exact deduplication;
- 2,376 generated 224 x 224 images;
- balanced classes within every split.

## Step 2: train model alternatives

```powershell
python src/train_models.py `
  --experiments `
    simple_cnn_full `
    simple_cnn_strict `
    mobilenet_v3_small_finetune_full `
    mobilenet_v3_small_finetune_strict
```

The command writes checkpoints to `models/trained` and comparison artifacts to `reports/training`. Model selection must use validation results and the common untouched test set, not training accuracy.

## Step 3: evaluate hybrid OCR

```powershell
python src/evaluate_hybrid.py
```

Tune OCR thresholds only on validation. Lock the thresholds before running the test split. Keep the source-group split intact throughout both stages.

## Step 4: optional 384-pixel research path

```powershell
python src/build_384_dataset.py --overwrite
python src/train_models.py `
  --data-dir data/processed_384 `
  --manifest data/manifests/generated_manifest_384.csv `
  --image-size 384 `
  --augmentation-profile camera `
  --experiments mobilenet_v3_small_finetune_full `
  --batch-size 16
```

The camera augmentation profile adds perspective, scale, translation, lighting variation, blur, grayscale, and small occlusion. It must not apply uncontrolled quarter turns because those would change the target label.

## Step 5: add real photographs

Record each image in `data/manifests/real_photo_manifest.csv`. Every physical receipt needs one stable `receipt_group`, and that group must appear in exactly one split.

```powershell
python src/prepare_real_photos.py
```

Recommended minimum collection:

- 50 different physical receipts;
- all four orientations;
- two scenes per orientation;
- Thai and English receipts;
- varied phones, distance, hands, glare, shadows, backgrounds, and perspective.

This target yields about 400 labeled real photographs. Use an untouched external holdout only after model and OCR thresholds are frozen.

## Step 6: verify

```powershell
python -m unittest discover -s tests -v
python src/evaluate_external_photos.py
python scripts/build_project_report.py
python -m streamlit run app.py
```

Check that the app's detected crop matches the receipt and that uncertain OCR evidence does not trigger automatic correction.

## Reproducibility controls

- Random seed: 4201.
- Split unit: physical source receipt.
- Input: RGB, aspect-preserving square canvas.
- Normalization: stored in each checkpoint.
- Labels and class order: stored in each checkpoint.
- Training optimizer and scheduler: saved in reports and code.
- Aggregate results: committed under `reports`.
- Project report: reproducibly generated by `scripts/build_project_report.py`.
- Private raw and generated data: excluded by `.gitignore`.
